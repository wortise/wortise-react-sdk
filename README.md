# Wortise SDK for React Native

[![npm package](https://img.shields.io/npm/v/@wortise/react-native-sdk.svg)](https://www.npmjs.com/package/@wortise/react-native-sdk)

A React Native module to show Wortise ads on Android and iOS: banner, interstitial, rewarded, app open and native. It includes an Expo config plugin.

## Install

```bash
npm install @wortise/react-native-sdk
```

Then follow the [integration guide](https://docs.wortise.com/react-native/sdk-integration/): it covers the Android and iOS project setup (also with Expo), the SDK initialization and every ad format.

The module contains native code, so it does not work in Expo Go: use a development build.
